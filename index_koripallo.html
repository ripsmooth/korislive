Grafiikkojen suorat linkit

Syötä ottelun ID. Sivusto muodostaa kaikille kuudelle grafiikalle kopiointivalmiit linkit. Voit myös liittää koko Basket.fi-ottelulinkin — ID poimitaan siitä automaattisesti.

Linkit käyttävät tähän indexiin määritettyjä kuutta HTML-tiedostoa. Jos tiedostot ovat GitHub Pagesissa samassa kansiossa kuin tämä index, suhteelliset linkit toimivat suoraan.
